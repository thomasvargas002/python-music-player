# Python Music Player

Python-based music application featuring a structured backend architecture with APIs, services, and frontend integration.

## Features
- Music search functionality
- Artist and album retrieval
- Structured backend/API organization
- Frontend integration
- File caching support

## Technologies Used
- Python
- FastAPI
- HTML/CSS/JavaScript
- REST APIs

## Purpose
Built as a collaborative learning project focused on backend structure, APIs, and software organization.
